# Data folder

Downloaded or computed files. Everything here except this README is created by the project and is **not committed** (listed in `.gitignore`); running the notebook or `bash 04_full_execution.sh` recreates it.

| File | What it holds | Created by |
|---|---|---|
| `go-basic.obo` | The Gene Ontology, release 2026-07-26, 32.2 megabytes. 48,340 terms read, 10,248 obsolete terms removed, 38,092 kept | Downloaded by Step 2 of the notebook from https://purl.obolibrary.org/obo/go/go-basic.obo |
| `HUMAN-uniprot.gaf.gz` | Human gene annotations, generated by UniProt on 2026-07-28, 12.1 megabytes. 910,476 lines read | Downloaded by Step 2 from https://current.geneontology.org/annotations/gaf/HUMAN-uniprot.gaf.gz |
| `go_term_embeddings.npz` | Cache of the term embeddings: one row of 384 numbers per kept term (38,092 terms), made with all-MiniLM-L6-v2. Computing it took 16 minutes 17 seconds on the processor | Created by the embedding step of the notebook; later runs load it |
| `answer_cache.json` | Cache of the language-model answers, so that a repeated run does not ask the model again | Created by the notebook |
| `site_to_gene_table.csv` | One row for each of the 865,859 sites of the EPIC array (616,598 with at least one gene name). Columns: `site`, `chromosome`, `position`, `gene_names` (names separated by semicolons, duplicates possible, empty if the site has no gene) and `gene_groups` (the region labels of the annotation) | Written by `01_missmethyl_check.R` from the Bioconductor package `IlluminaHumanMethylationEPICanno.ilm10b4.hg19` (genome build hg19); read by Step 11 |

## Notes

- A site can belong to several genes (for example the protocadherin gene clusters), so one site can add many genes to a list.
- Gene names come from the array annotation and can differ from the symbols in the UniProt file (older names, antisense and pseudogene entries); 25,670 names in the study background became 16,686 matched genes.
- The two annotation sources differ: the R step uses `org.Hs.eg.db` and `GO.db` (Bioconductor 3.23), the Python steps use the two downloaded files above.
- If a file is missing, the notebook downloads or recomputes it, except `site_to_gene_table.csv`, which needs the R step (`Rscript 01_missmethyl_check.R`).
