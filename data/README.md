# data

Downloaded and cached files for the notebook. Nothing here is committed except this file.

| File | What it is | How it was obtained |
|---|---|---|
| `go-basic.obo` | The Gene Ontology: release 2026-07-26, 32.2 megabytes. Terms with identifier, name, definition and parent terms | Downloaded by Step 2 from https://purl.obolibrary.org/obo/go/go-basic.obo |
| `HUMAN-uniprot.gaf.gz` | Human gene annotations: generated by UniProt on 2026-07-28, 12.1 megabytes (compressed, do not unzip) | Downloaded by Step 2 from https://current.geneontology.org/annotations/gaf/HUMAN-uniprot.gaf.gz |
| `go_term_embeddings.npz` | Cache of the term embeddings (38,092 terms, 384 numbers each) and their identifiers | Created by Step 4; it took 16 minutes and 17 seconds on the processor |
| `answer_cache.json` | Cache of every answer of the language model, so a repeated run does not ask again | Created by Step 7 |

The two data files are described by the Gene Ontology website as Creative Commons Attribution 4.0. If a cache file is missing, the notebook creates it again on the next run.
